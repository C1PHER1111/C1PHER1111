- 🔭 **Current Operations:** Engineering high-dimensional tensor pipelines: einsum-style contractions, strided memory views, and broadcasting semantics, profiled against the roofline model to separate memory-bound from compute-bound regimes.
- 👯 **Synergy Vectors:** Open to collaboration on ML / DL research, custom autodiff engines, numerical-methods libraries, and systems-level optimization of training and inference stacks.
- 🤔 **Critical Assistance:** Seeking rigorous review of hand-written C++ matrix kernels (cache-blocked GEMM, register tiling, SIMD vectorization, prefetch scheduling), mixed-precision accumulation stability, and GPU tensor execution graph partitioning.
- 🌱 **Knowledge Intake:** Convex and non-convex optimization, variance-reduced stochastic gradient methods, information geometry, CUDA graph capture, kernel fusion, and compiler-level lowering of tensor IR.
- 💬 **Transmission Core:** Ask me about reverse-mode autodiff over computation DAGs, loss-landscape geometry in overparameterized networks, or why stochastic gradient noise behaves as implicit regularization.

Same doctrine: when the model of a system declares a solution impossible, derive a better model. Raw logic over raw resources.
